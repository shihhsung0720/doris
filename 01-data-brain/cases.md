## 案例格式

每筆包含：
- **名稱 / 標題**
- **時間**（YYYY-MM）
- **平台 + 數字**（讚 / 留言 / 觀看）
- **結構公式**（X VS Y / POV / 痛點金句 / 直接引用 / ...）
- **角度**（媽媽vs阿嬤 / 媽媽vs老公 / ...）
- **可講畫面**（這支可以舉例什麼主題）
