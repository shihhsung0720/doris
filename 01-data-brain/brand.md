### 招牌結構公式（1-4 從爆款回推 5/5、5+ 從她親筆腳本抽出）
1. **「X VS Y」對比** — 例：「媽媽VS阿嬤」
2. **「當⋯⋯時」/「⋯⋯終究是別人的」痛點金句**
3. **「POV：你們家⋯⋯」共感引導**
4. **直接放小孩 / 老公的原話當標題** — 例：「我要阿嬤」
5. **藏鏡人 Q&A 精簡版**：藏鏡人只在 3 個切點出現（開場問題 / 過場問「必買呢」/ 結尾打岔 gag）、中間讓闆娘一路講完 — 適合「過來人分享」型（智商稅 / 育兒 / 業配）
6. **時間戳 + 平行剪輯 + 訊息 callback**：`(9:00/10:00/10:30)` 時間軸推進 + 雙人平行動作對比 + 結尾用手機訊息（非對白）收 — 適合「無對白動作對比」型（男女 / 媽媽阿嬤 / 上班日常）、30-35s 短影音

### 文案開頭句型庫（除上面公式外）
- 「你知道嗎？」
- 「跟你說⋯」
- 「媽——」（呼喊起手）
- 「廢話不多說、直接分享 [X] 心得」（過來人分享型專用、可跳過長 setup）

### 標誌句格式庫（持續累積）
`「X VS Y」` / `「當⋯⋯時」` / `「⋯⋯終究是別人的」` / `「POV：你們家⋯⋯」` / `「我要X」` / `「你有事嗎」` / `「笑S」` / `「來亂ㄟ」` / `「你知道嗎？」` / `「跟你說⋯」` / `「廢話不多說、直接分享 X 心得」` / `「歸剛就是⋯」` / `「已封肚」`

### 創作習慣
- **人稱**：最常用「你」（拉受眾入戲）
- **結尾**：問問題收尾（不用 CTA、不用留白）
  - 收尾前常加**軟性 disclaimer**：「但每個⋯需求 / 情況不一樣~」→ 避免絕對化（技術實現 [6] 不絕對化紅線）
  - **訊息 callback 收尾**（另一種模式）：用手機訊息 / LINE 對話當結尾元素、不是對白 → 真實生活感、觀眾腦補聲音、例：老公傳「阿你人勒？」
- **製作**：脫稿即興、不寫腳本、不打字稿
- **入鏡**：8 成帶老公 / 小孩、角色隨機（沒固定誰是誰）
- **符號**：標題常用 😂😂😂（連 3 個大笑、情緒掛鉤）
- **動作提示風格**：具體感官 / 身體反應 / 表情反應（例：「抖一下害怕回憶的感覺」、「拍自己肚子」、「推老公頭」、「翻白眼」、「傻眼」）— 不寫抽象情緒、寫可拍的動作

### 不會講的話 / 不會用的口氣
- **批判的話**（不罵人、不戰）
- **絕對化句型**（「一定怎麼樣」「絕對⋯⋯」 — 保留模糊空間、不講死）
